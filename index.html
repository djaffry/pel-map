    PeL Map — quick guide

    Getting started

    • Load people via Load example or upload a file (left panel).
    • Set Min / Max span and click Auto-rebalance to build the tree.
    • Click a card to edit or delete a person; ＋ on a leader adds a report under it.
    • Right-click a card (or its ⋯) for all its actions — edit, add, flag, fix link.
    • Drag a person onto a leader to move & pin them; drag empty canvas to pan.

    Legend — roles

    • VP — head, cross-BU
    • HO — single stream lead
    • TA — stream role (levels 1–3)
    • SE — stream role (levels 1–4)
    • NSE — non-SE, marked for deletion

    Legend — markers & halos

    • 📌 / 🔒 fixed — pinned to a manager; survives Auto-rebalance.
    • ⚠ dup — another person shares this exact name.
    • Red halo / outline — a constraint error (shown on the card).
    • Amber outline — a warning (e.g. span below min).
    • Orange halo — you flagged this node (⚑); an optional note shows in the Summary overview.
    • Capacity pips — filled = current directs, dashed = open slots (drop targets) up to max span.
